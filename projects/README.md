## 新增项目

1. 复制 `_TEMPLATE/` 为 `projects/<项目名>/`
2. 把源码、文档、测试数据放进该目录
3. 按 `_TEMPLATE/README.md` 的结构填写说明
4. 在 `docs/uploads.md` 的检查清单上逐项确认
5. 回到本文件表格里登记一行

> 项目必须是从其他目录**复制**进来的副本，不要在这里直接引用外部工程路径。
