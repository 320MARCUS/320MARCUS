# Hi, I'm Marcus 👋

> 电子信息工程 · 项目与工程实践记录

## 关于我

电子信息工程专业在读本科生，关注嵌入式系统与数字信号处理。

本仓库记录我的学习与工程实践：每个项目从需求分析、方案设计到实现与测试独立完成，代码、原理说明与实测数据一并开源，供参考与交流。

| 类别 | 内容 |
